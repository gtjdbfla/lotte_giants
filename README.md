# 꼴데연구소 · GGOLDE LAB

**못한 정도 말고, 희망을 줬다 뺏은 정도.**

KBO 경기 흐름을 되돌아보는 비공식 팬 연구 프로젝트. 공개 첫 버전은 2024·2025 정규시즌 각 720경기이며, 2023년 720경기는 이전 시즌 학습 자료로 사용한다. 롯데가 1등이 되도록 조정하지 않는다.

공개 주소: https://yulmserver.tail261e6c.ts.net:10000/ggolde/

## 화면은 두 탭

1. **구단별 희망고문** — 시즌/전체 기간의 10구단 점수, 후반 리드 후 패배, 희망 확보 후 패배율, 스트레스 경기 TOP 6, 경기 상세 곡선.
2. **롯데 선수 꼴데력** — 야수 타격 / 야수 수비 / 투수. 투수는 전체를 기본으로 선발 등판·불펜 등판 필터를 제공한다. 선수는 해당 시즌 롯데 소속 경기만 집계한다.

선수 이름과 경기 카드를 눌러 실제 장면을 확인할 수 있다. 경기 링크는 공유 가능하다. 실시간/당일 집계는 아직 제공하지 않는다.

산출물:

## 산식 v0.1

### 기대승점

`WE = P(승리) + 0.5 × P(무승부)`에 해당하는 기대값을 fractional-logit으로 추정한다. **순수 승리확률 또는 공식 WPA가 아니다.** 이닝·초말·아웃·주자·점수 차를 입력으로 쓰고 팀·선수 이름은 입력하지 않는다. 같은 경기의 많은 타석이 학습을 지배하지 않도록 경기별 가중치를 보정한다.

2024는 2023으로, 2025는 2023~2024로 학습한다. 각 경기 마지막 결과는 승 1 / 무 0.5 / 패 0으로 종료한다. 결과를 경기 중 모형 입력으로 사용하지 않는다. 검증 오차는 타석 상태별 기대승점 MSE이며 관측들은 경기 안에서 독립이 아니다. 연장 제한 규정별 모형 분리·세밀한 calibration은 후속 과제다.

### 구단 점수

패배 경기에서만 세 요소를 계산한다.

- 유리함 회수: `65 × max(clip(2×(WE−0.5),0,1) × 이닝가중치)`
- 추격 후 회수: 과거 WE가 35% 미만인 시점 이후 6회 이상에서 45% 이상까지 회복한 폭, 최대 25점
- 반복 회수: 6회 이후 WE 65% 이상 → 40% 이하가 된 사이클, 최대 10점

이닝가중치는 1회 0.1에서 9회 1까지 증가한다. 경기 시작 50%는 희망으로 세지 않는다. 같은 경기의 실책·불펜·접전 카드는 설명이며 대표 점수에 중복 가산하지 않는다.

구단 대표 점수는 패배 경기 평균을 리그 평균 10경기분으로 보정한다. 시즌 합계는 별도로 표시한다. 희망 확보 후 패배율은 **최종 결과가 나오기 전** 6회 이후 WE 65% 이상을 경험한 경기를 분모로 사용한다. 최종 승리의 100% 자체를 희망 기회로 넣지 않는다.

### 선수 점수

타격·투구: 롯데 기준 음수 WE 변화에 후반·희망·접전 가중치를 적용한다. 3점 차 이내에서 WE 25%를 넘는 상태가 기회다. 후반 가중치는 4회부터 증가하며 9회에 1, 초반은 0.15다. 손실의 단위는 가중 기대승점 %p다. 기회당 손실을 평균 20기회분으로 보정한다.

지수는 보정된 기회당 손실을 **2024 롯데 동일 부문 선수 분포**와 비교한 0~100 분위다. 2025 순위를 강제로 0~100으로 늘리지 않는다. 같은 분위의 선수는 기회당 손실로 정렬한다. 누적 스트레스 정렬도 제공한다. 기본 표시 조건은 타격 100타석 또는 투구 60상대 타석, 스트레스 기회 15회 이상이다. 기준 미달 선수도 잠정값으로 확인할 수 있다.

투수 선발/불펜 역할은 박스스코어의 해당 경기 선발 투수로 구분한다. 실책 출루 타석은 투수 손실에서 제외하지만 **모든 수비·승계주자·주루 영향을 분리한 순수 책임 통계는 아니다.** LI/Clutch를 아직 계산하지 않으며 해당 이름으로 표시하지 않는다. 개인의 평소 실력 대비 초과 실패를 완전히 분리한 지표도 아니므로 미래 능력 추정에 사용하지 않는다.

수비: 실책 순간의 주자·아웃·점수 전후 WE 변화만 사용한다. 원 경기 공식 실책 명단·수비하는 초말·선수 ID를 대조한다. 이름이 같은 상대 선수를 구분하고 책임이 불명확한 장면은 개인 순위에서 제외한다. 수비 이닝/처리 기회가 없어 기회당 실책률을 표시하지 않는다. 수비 지수는 손실 누적값의 2024 기준 분위이고 30경기 이상 기본 표시다. 정상 처리했을 때의 가상 아웃 손실은 미반영되어 일부 실책 손실이 작게 추정될 수 있다.

### 현재 검산

- 2023~2025 매년 720경기의 복원 최종 점수와 별도 경기 결과 자료가 모두 일치
- 2024 롯데 실책: 123개 발생 확인, 야수 책임 112개, 투수 10개, 불명확 1개
- 2025 롯데 실책: 111개 발생 확인, 야수 책임 99개, 투수 11개, 불명확 1개
- 실책 합계는 KBO 팀 수비 기록의 시즌 합계와 일치
- 팀 경기 수·승패 보존·경기 종료값·선발/불펜 타석 분할·스트레스 의미의 회귀 검증

## 홈서버

`docker compose up -d`로 Caddy가 `127.0.0.1:8090`에서 정적 파일을 제공한다. 기존 Funnel의 10000 포트에 `/ggolde/` 경로를 추가하는 방식이며 매크로 대시보드의 `/`는 유지한다. `Caddyfile`은 경로가 제거되어 전달되거나 그대로 전달되는 경우 모두 지원한다.

코드/결과는 GitHub에서 내려받되 원천 데이터는 필요할 때만 별도 로컬 배치로 생성한다. 대시보드 공개 프로세스에는 수집기·키·관리 API가 없다. 대규모 데이터 갱신을 자동화할 때는 준비 디렉터리에서 검산을 통과한 스냅샷을 원자적으로 공개하는 배포 단계를 추가해야 한다. 현재 버전에는 자동 갱신 크론이나 GitHub Actions를 설치하지 않는다.
